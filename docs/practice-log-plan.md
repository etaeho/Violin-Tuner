# 연습 기록 구상안

> 상태: **제안 (미구현)** · 근거: [research.md](research.md) — Soundcorset·TonalEnergy의 강점(연습 시간 통계, 음정 기록)

## 핵심 방향
- **버튼 없이 자동 측정**: 마이크가 이미 계속 듣고 있으므로, 바이올린 소리가 감지된 시간만 연습 시간으로 센다. (START 버튼을 없앤 것과 같은 철학)
- **음정까지 기록**: 시간만 세는 다른 앱과 달리, 연주한 음마다 맞았는지를 모아 "자주 틀리는 음"을 지판 위에 보여준다 → 우리만의 차별점.
- 계정·서버·인터넷 없이 폰에만 저장.

## 위치
- 하단 **5번째 탭 `기록`** (Tuner · Metro · Finger · Drone · 기록)
- 모든 탭 상단에 작은 칩: `오늘 23분 / 30분` (누르면 기록 탭으로)

## 1. 연습 시간 타이머
| 항목 | 내용 |
|---|---|
| 자동 측정 | 튜너가 음을 확정한 순간 = 연주 중. 소리가 **10초 이상** 없으면 일시정지로 봄 (설정 가능) |
| 구분 | 연주 / 튜닝(개방현 위주 + 튜너 탭) / 메트로놈 사용 / 드론 사용 시간 따로 집계 |
| 목표 | 하루 목표 시간(기본 30분) → 진행 링, 달성 시 진동 + 알림 토스트 |
| 집중 타이머 (선택) | 25분 연습 / 5분 휴식 반복 |

## 2. 하루 연습량
- **오늘 카드**: 큰 숫자 `42분`, 목표 링, 연속 연습일 🔥, 오늘 음정 정확도
- **달력 히트맵**: 최근 12주, 연습량만큼 진하게 (GitHub 잔디 형태)
- **주간 막대 그래프**: 요일별 연습 분 + 음정 정확도 꺾은선
- 메트로놈 최고 BPM 기록 (스케일 속도 향상 확인용)

## 3. 음정 정확도 추이
| 지표 | 계산 |
|---|---|
| 정확도 % | 0.15초 이상 유지된 음 중, 허용 범위(±설정값) 안에 든 비율 |
| 평균 오차 | 음별 평균 센트 (+ 높음 / − 낮음) |
| 추이 | 최근 30일 일별 정확도 꺾은선 |
| **자주 틀리는 음** | 음별 집계 → 상위 5개 `C♯5 평균 +12¢ (높음)` |
| **지판 히트맵** | 지판 탭에서 토글 → 자주 높은 음은 빨강, 낮은 음은 파랑으로 표시 ("3번 손가락이 늘 높다" 같은 습관 발견) |

- 튜닝 중 개방현은 정확도 계산에서 제외 (튜너 탭 + 개방현 + 긴 지속음 = 튜닝으로 판단)
- 드론 2단계가 생기면 드론 대비 순정 음정 정확도도 같이 기록

## 화면 (기록 탭, 위 → 아래)
1. 오늘 카드 (시간 · 목표 링 · 🔥연속일 · 정확도)
2. 12주 히트맵
3. 주간 막대 + 정확도 선
4. 자주 틀리는 음 Top 5 → 누르면 지판 탭 히트맵으로 이동
5. 설정: 목표 시간, 쉬는 시간 판정(초), 기록 초기화

테마: 테이프 = 어두운 그래프 / 빈티지 = 가죽 연습 노트 + 황동 링, 손글씨풍 숫자

## 데이터 (localStorage, 하루 요약만 저장)
```js
// vt.log.days
{
  "2026-11-06": {
    playMs, tuneMs, metroMs, droneMs,       // 시간
    notes, inTune, sumAbsCents,             // 정확도
    bpmMax,
    perNote: { "A4": [개수, 맞은수, 센트합, |센트|합], ... }
  }
}
```
- 하루 약 1KB → 1년 약 400KB (localStorage 한도 내). 1년 지난 날은 자동 정리.
- 10초마다 + 앱을 내릴 때 저장.
- 원본 음성/프레임은 저장하지 않음 (용량·개인정보).

## 기술 메모 (추가 패키지 없음)
- 새 파일 `src/practice.jsx`: `usePracticeLog()` — 튜너가 음을 확정할 때 `feed(note, cents, now)`, 매 프레임 `tick(now)` 호출 (연주 명령 `commands.jsx`와 같은 구조)
- 그래프는 SVG로 직접 그림 (차트 라이브러리 없음)
- 마이크는 앱이 화면에 있을 때만 켜지므로 **화면을 켜 둔 연습만 기록됨** (이미 화면 꺼짐 방지 중)

## 단계별 구현
1. **연습 시간**: 자동 측정, 오늘 카드, 목표 링, 히트맵, 주간 막대, 상단 칩
2. **음정 정확도**: 정확도 %, 추이, 자주 틀리는 음, 지판 히트맵
3. **확장**: 연습 메모, 기록 백업/내보내기(JSON 공유), 연습 알림(네이티브 알림 필요)
