# 드론 모드 구성안

> 상태: **1단계 구현됨** (src/drone.jsx) · 2·3단계 미구현 · 근거: [research.md](research.md) — 선생님·포럼이 음정 연습에 가장 권하는 방식, 지원 앱 드묾

## 개념
근음(+5도 등)을 **계속 울려 두고**, 그 위에서 연주한 음이 드론과 **순정 음정**으로 맞는지 보여준다.
튜너(평균율 기준 바늘)와 달리 "울림이 맞는가"를 연습 → 실제 합주 음정에 가까움.

## 위치
- **하단 4번째 탭 `Drone`** 추천 (튜너/메트로놈과 화면 성격이 달라 분리)
- 메트로놈과 동시 사용 가능 (드론 + 박자 연습)

## 화면 구성 (위 → 아래)
| 영역 | 내용 |
|---|---|
| ① 근음 선택 | 12음 원형 휠(5도권 순서) + 옥타브 ±. 빠른 칩 `G D A E`. 지판 탭 조표와 연동 옵션 |
| ② 화음 구성 | 토글: 근음 / +5도 / +옥타브 / +장3도 / +단3도 — **순정 비율**(3:2, 2:1, 5:4, 6:5)로 생성 |
| ③ 음정 게이지 (메인) | 지금 연주한 음 이름 + **드론 대비 음정**(예: "장3도") + 순정 기준 ±센트. 맞을수록 원의 물결(맥놀이)이 잔잔해지는 시각화, 맞으면 초록 |
| ④ 음색 · 볼륨 | 첼로풍(톱니파+저역필터) / 오르간(사인 배음) / 부드러움(사인). 볼륨, 페이드 인·아웃 |
| ⑤ 하단 | 큰 ▶ 재생/정지 + "메트로놈 같이" 토글 |

빈티지 테마: 근음 휠을 황동 다이얼, 음정 게이지를 아날로그 바늘로.

## 기술 메모 (추가 패키지 없음)
- Web Audio 오실레이터로 생성 (기존 기준음 코드 확장).
- **스피커 드론이 마이크로 다시 들어가는 문제**
  (연주 명령 오작동 때 겪은 것과 같은 구조):
  - 마이크 입력에 드론 주파수·배음 **노치 필터**(BiquadFilter notch) 적용
  - 드론과 같은 음을 연주하는 경우는 구분이 어려워 **이어폰 사용 권장** 안내
  - 드론 재생 중엔 연주 명령(패턴) 감지 끔
- 순정 음정 판정: 드론 근음 대비 비율을 가장 가까운 순정 음정(1/1, 16/15, 9/8, 6/5, 5/4, 4/3, 45/32, 3/2, 8/5, 5/3, 9/5, 15/8)과 비교해 센트 차이 표시.

## 단계별 구현
1. **기본 드론** — 근음 선택, +5도/옥타브, 음색, 볼륨, 페이드, 재생 상태 저장
2. **음정 게이지** — 순정 음정 판정 + 노치 필터 + 명령 감지 차단
3. **스케일 연습** — 조표 선택 → 근음 자동, 스케일 음을 순서대로 표시하고 음별 정확도 기록

## 같이 하면 좋은 것
- **순정 5도 조율 모드** (튜너 탭): A 기준 E +2¢, D −2¢, G −4¢ — 드론 모드와 같은 순정률 계산 공유
